- Monitor: `docker-compose.yml` now hands the monitor its container start/stop
  bearer token, as `CONTROL_TOKEN: ${MONITOR_CONTROL_TOKEN:-}`. It is the same
  `.env` value the server already sends as `MONITOR_CONTROL_TOKEN`
  (system_3 #10680). Before this, the monitor never received a token, so every
  Stop or Start from System health answered 503 `control_disabled`. With
  `MONITOR_CONTROL_TOKEN` unset, nothing changes. Set it in `.env`, then
  recreate monitor and server. `tests/compose_secret_scope_unit.sh` asserts
  that the token reaches monitor and server only.
