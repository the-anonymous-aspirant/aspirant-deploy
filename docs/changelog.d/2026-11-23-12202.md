- Lake skeleton: `explorer-decrypt-up` no longer leaves the explorer down
  when the key is refused (system_3 #12202). On 2026-11-22 a mistyped key
  stopped `explorer-api` for 18 hours, and every restart failed on the deleted
  key file. The verb now deletes the key file and recreates the service with
  decrypt off, without the key's variables, says so in one line, and still
  exits non-zero. Its closing message and `docs/LAKE_SKELETON.md` now say that
  a restart, unlike a recreate, leaves a decrypting `explorer-api` stopped.
