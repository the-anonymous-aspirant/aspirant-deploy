- `scripts/update-dns.sh` manages the apex only while it is an A record,
  and `ROOT_RECORD_ID` is now optional (system_3 #10829-A3). It used to PUT
  the apex back as an A record whenever its content differed from the cell's
  IP. Once the apex is the Cloudflare Tunnel's CNAME, that would have undone
  the cutover every five minutes. Each record is now compared on its own
  content, so a drifted `home.the-aspirant.com` (the SSH entry point) is
  repaired even while the apex is current. A deleted apex record no longer
  kills the run silently before the SSH record is checked.
