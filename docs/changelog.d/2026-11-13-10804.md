- tests: `bash tests/run_unit.sh` runs every `tests/*_unit.sh`, the changelog
  suite included, and exits non-zero if any fails (system_3 #10799-A3). It is
  this repo's verify command; before, each verify chained suites by hand, so
  nothing guaranteed the changelog check ran. One suite,
  `lake_client_publish_unit.sh`, fails on main because the compose no longer
  pins the lake client (#4475). It is listed as known-failing, with its fix
  task (system_3 #10808), and still runs and prints. A listed suite that
  starts passing fails the run, so the entry is removed rather than left to
  hide a regression. All suites take about ten minutes on the cell.
