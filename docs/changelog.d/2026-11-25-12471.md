- Lake skeleton: `destroy` no longer deletes real data (system_3 #12471,
  under #11565). It refuses, before stopping anything, unless the tree is
  empty, carries the `.fixtures-only` marker that `up` writes on a fresh
  root and every real-data verb removes, or `LAKE_SKELETON_DESTROY_REAL_DATA`
  names its resolved path exactly. It also refuses a path that is not the
  skeleton's own: one less than two levels deep, on `/data`, or holding
  anything the script did not create.
