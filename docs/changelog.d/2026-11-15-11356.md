- Added a `cloudflared` service, the Cloudflare Tunnel connector (system_3
  #10829-A1). It is profile-gated and pinned by digest, publishes no ports,
  and sits on its own `tunnel` network, shared only with the live client slot,
  so a dashboard edit can never route to another service. It runs as the
  image's own user, read-only, with every capability dropped. It reads its
  connector token from a 0400 file outside the repo
  (`/data/aspirant/cloudflared/token`, owned by 65532), never argv or
  `environment:`. `deploy-client.sh` now puts the live blue/green slot on
  `tunnel` with the alias `client-active`, the tunnel's target, so a slot flip
  never strands it. Nothing changes for visitors yet: the public `:80` stays
  until the cutover. `docs/OPERATIONS.md` gains install, verify, rotation and
  rollback.
