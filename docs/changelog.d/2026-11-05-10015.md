- Added `scripts/e2e-stack.sh` (up / down / status), a disposable end-to-end stack for the invoicing app: the served server and client images pinned by image ID, a scratch Postgres, a synthetic seed (`scripts/e2e_stack_seed.py`) and three per-run logins (owner, Admin, non-owner Member). Secrets are generated per run, kept in 0600 files and never printed. The only port is published on loopback, and `down` removes everything the run created. Documented in `docs/E2E_STACK.md`; tested by `tests/e2e_stack_unit.sh` (system_3 #10015, #9980, security ruling #9979).
